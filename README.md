# NEXUS AI · 大学人工智能协会

深色 / 浅色双主题的单页社团官网界面，面向大学 AI 社团场景。整个站点为纯前端静态页面，主题切换与粒子背景使用原生 JavaScript，无后端、真实表单或业务功能。

## 预览

直接双击 `index.html`，或在浏览器中打开即可。无需安装依赖或启动构建服务。

- 浅色主题预览：`preview-light.png`
- 深色主题预览：`preview-dark.png`

## 页面内容

- **首页 Hero**：社团定位、秋季招新状态、社团数据、NEXUS CORE 视觉装置
- **关于社团**：社团简介、成员与项目数据、关注方向、三条社团原则
- **项目进度**：重点项目 KITE 的进度、阶段与团队信息，另附三个在研项目卡片
- **活动公告**：近期工作坊、论文共读、分享会、黑客松，以及 NEXUS Lab 公告栏
- **学习资料**：资料分类、新生学习路线、RAG 实战教程、资料列表
- **加入我们**：招新说明、截止时间与申请入口界面
- **页脚**：站点导航、联系方式与社交入口

## 双主题设计

- **深色模式**：`#07090e` 蓝黑底，雾蓝重点色，冷调暗色界面（保留原版设计）
- **浅色模式**：`#f3ede2` 米白底，棕色与黑色文字、边框、图标和强调背景，整套界面不再使用蓝色
- 浅色模式的 Hero 右侧核心视觉重绘为米色纸感仪器面板：暖棕轨道、深咖啡核心、奶油色浮层卡片
- 项目预览、活动海报和代码窗口在浅色模式下保持深咖色墨块，并使用暖金 / 沙棕高光
- 主题切换按钮位于页面顶部右侧；桌面显示模式文字，移动端保留太阳 / 月亮图标
- 支持三种初始化方式：读取上次手动选择 → 跟随系统 `prefers-color-scheme` → 默认深色
- 切换结果写入 `localStorage`，刷新后保持；跨标签页同步

## 点线粒子背景

- 复用本地 `particle-net.js` 引擎，固定为全站背景层：99 点基准、按视口密度自适应、两点连线、鼠标推开粒子
- **浅色模式使用纯黑粒子，深色模式使用纯白粒子**；画布整体透明度降低，避免干扰正文阅读
- 主题切换时粒子颜色实时更新；支持 `prefers-reduced-motion`，页面隐藏时自动暂停
- 主内容与卡片位于粒子层之上，保证可读性；浅色 / 深色的小面板保持独立层次

## 其他

- 视觉元素主要由 HTML / CSS 绘制，粒子背景使用本地 Canvas 引擎；无外部图片、字体或 CDN 依赖，可离线预览
- 已适配 320px—1920px 宽度，包含平板布局、移动端折叠菜单与单列卡片
- 除页内锚点导航、原生折叠菜单、主题开关和粒子鼠标交互外，其余按钮均为界面占位
